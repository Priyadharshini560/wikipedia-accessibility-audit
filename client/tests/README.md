# Wikipedia Accessibility Audit

## Project Overview
This project focuses on auditing the accessibility of the Wikipedia website using Google Lighthouse and manual keyboard testing.

## Website Audited
- Website: https://www.wikipedia.org/
- Tool: Google Lighthouse
- Testing: Keyboard navigation and responsive design

## Project Structure
- client/ – Frontend files
- server/ – Backend files
- docs/ – Audit reports and documentation
- tests/ – Accessibility test cases

## Audit Results
- Lighthouse Accessibility Score: 100
- Performance Score: 100
- Best Practices Score: 77
- SEO Score: 92

## Testing Methods
- Keyboard navigation
- Image alternative text
- Form labels
- Colour contrast
- 200% zoom testing
- Responsive design testing

## Objective
To identify accessibility and architecture issues and recommend suitable improvements.
