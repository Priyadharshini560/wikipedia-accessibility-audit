# Project Architecture

## 1. Overview
This project follows a monorepo-style architecture to organize frontend, backend, documentation, and testing files.

## 2. Architecture Boundaries

### Client
Responsible for the user interface and frontend interactions.

### Server
Responsible for backend logic, APIs, and data processing.

### Docs
Stores accessibility audit reports, screenshots, and architecture documentation.

### Tests
Contains manual and automated accessibility test cases.

## 3. Local Setup
1. Clone the GitHub repository.
2. Open the project folder in VS Code.
3. Review the client and server directories.
4. Follow the setup instructions for each application.

## 4. First Vertical Feature Slice
The first feature is an Accessibility Audit Dashboard.

It will allow users to:
- View Lighthouse audit scores.
- Read accessibility findings.
- View recommended solutions.
- Track issue status.

## 5. Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Version Control: Git and GitHub
- Testing: Google Lighthouse
